# TensorV 三维实时预览

1. 在 VS Code 中打开这个文件夹并信任工作区。
2. 打开 `vectors_and_tensor.py`。
3. 按 Ctrl+Shift+P，选择“TensorV: 三维实时预览（自动运行）”。
4. 右侧“三维视图”中选择 `vectors` 查看箭头，选择 `cube` 或 `transposed` 查看立体张量。
5. 修改左侧坐标或张量形状，停止输入约 650 ms 后右侧更新，无需保存。

鼠标拖动旋转，滚轮缩放，右键拖动平移。悬停方块可查看原始索引和数值。

通过“TensorV: 选择 Python 解释器”选择安装了 PyTorch 和 NumPy 的环境。仓库不绑定某台电脑上的解释器路径。

自动运行会执行整个文件，建议使用独立的张量实验文件。它查看语句执行后的快照，不是断点调试器。

## English

1. Open this folder in VS Code and trust the workspace.
2. Select a Python interpreter with PyTorch and NumPy via “TensorV: 选择 Python 解释器”.
3. Open `vectors_and_tensor.py` and run “TensorV: 三维实时预览（自动运行）” from the Command Palette.
4. Select an execution step where the variable exists, then choose `vectors` for arrows or `cube` / `transposed` for tensor cubes in the 3D tensor dropdown.
5. Edit the code and pause typing for about 650 ms. Unsaved changes update the view.

Drag to rotate, scroll to zoom, right-drag to pan, and hover to inspect values. Automatic execution reruns the entire file; use trusted tensor experiments.
